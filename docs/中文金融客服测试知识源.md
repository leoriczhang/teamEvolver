# 中文金融客服测试知识源

仓库内置 `teamEvolver/skillminer/data/中文金融客服测试/`，用于远程部署后验证知识源管理、并行挖掘、知识补证、Skill/Benchmark 生成、人工编辑和提交进化的完整流程。

- 八类主题、八个 Markdown 文件、三十二段中文对话。
- 覆盖产品咨询、账户与交易、技术支持、投诉纠纷、营销活动、财务规划、风险安全及其它服务。
- 公开样本中的手机号码、姓名、银行卡号等字段已统一替换为中文占位符，不包含真实模型密钥或项目凭据。
- 部署后可在控制台“知识源”中直接选择 `中文金融客服测试`，无需再次上传。

样本筛选自 [DianJin/DianJin-CSC-Data](https://huggingface.co/datasets/DianJin/DianJin-CSC-Data)。原始数据集采用 MIT License；使用与再分发时应继续遵循其许可要求。
