## 已覆盖的一致性与安全场景

TE 重复并发受理、租户/主体隔离；候选变更使旧批准失效；取消后迟到上传被 OV 执行代次拒绝；篡改/过期 grant、撤权后发布失败；提交响应丢失按原键获得唯一回执；同基线竞争、重基准再审、历史回滚成为新 generation；租约过期重领；准备状态中断恢复；队列上限与瞬时失败重试；历史导入不能直接成为事实；HTTP/MCP 工具中没有正式发布或业务写操作。

## 仍未完成或需真实环境验收

- 完整原生 TE 页面到 OV 存储、原文检索、网络 MCP 的联合部署验收；当前 harness 不替代该项。
- OV 原生较大回归 16 项失败需按运行依赖与历史行为逐项处理；基线复核已确认 16 项可在修改前复现，结果见机器报告。未验证前不能声称主分支兼容全部通过。
- 来源事件给出影响清单并立即阻断读取，但跨来源自动依赖修复尚未实现；撤回超时需按原事件键重试，尚无独立撤回任务看板。
- 历史 enhancer 包导入只保留隔离草稿和决策记录；旧 OV native task 的历史引用/审计映射尚需迁移运维清单，不自动搬迁旧任务。
- 当前本体增强检索主要按实体别名展开；完整概念关系扩展、跨领域歧义消解、独立 OR 证明及反馈分派闭环未完成。
- 真实业务 CQ01—CQ12 金标、万文档规模、人工审核成本和跨库恢复未执行；业务写动作不适用且未开放。
- frank 需要在实际租户下确认 OV 用户凭证、当前权限、签名公钥信任和 PG 可用。默认关闭不等于测试环境已经启用。
