# Selection Priority

当目标冲突时，按以下优先级决策：

1. 先满足来源覆盖硬约束
2. 再满足目录来源的最小采样密度
3. 再避免单文件来源整份复制
4. 再保证每个样本包内部具备多种关键张力维度
5. 再按更高层主题组织样本包
6. 再优化样本关系质量
7. 再尽量覆盖稳定/冲突/失败/边界/伪相似五类
8. 再优化全局文件覆盖
9. 最后考虑目录镜像完整性

## 重要提醒
- “稳定 / 冲突 / 失败 / 边界 / 伪相似”是每个样本包内部尽量都应具备的关键维度
- 它们不应直接充当不同样本包之间的固定主题分工
- 样本包之间应按更高层、由数据归纳出来的主题来区分
